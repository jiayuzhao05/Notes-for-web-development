# 静态资源服务器

### 步骤 1: 处理请求路径

```javascript
// 获取请求路径
let requestPath = req.url

// 根路径映射到 index.html
if (requestPath === '/') {
  requestPath = '/index.html'
}
```

### 步骤 2: 构建文件路径

```javascript
// 使用 path.resolve 构建完整的文件路径
const publicDir = path.resolve(__dirname, 'public')
const filePath = path.resolve(publicDir, requestPath.slice(1)) // 去掉开头的 /
```

### 步骤 3: 检查文件是否存在

```javascript
// 使用 fs.promises.stat() 检查文件
try {
  const stats = await fs.promises.stat(filePath)
  
  // 检查是否是文件
  if (!stats.isFile()) {
    // 处理目录或其他情况
    return
  }
  
  // 是文件，继续处理
} catch (error) {
  // 文件不存在，返回 404
  res.writeHead(404)
  res.end('文件未找到')
}
```

### 步骤 4: 读取文件内容

```javascript
// 使用 fs.promises.readFile() 读取文件
const content = await fs.promises.readFile(filePath)
```

### 步骤 5: 设置响应头和发送内容

```javascript
// 获取文件扩展名
const ext = path.extname(filePath)

// 根据扩展名设置 MIME 类型
const mimeTypes = {
  '.html': 'text/html',
  '.js': 'application/javascript',
  '.css': 'text/css'
}
const contentType = mimeTypes[ext] || 'application/octet-stream'

// 设置响应头并发送内容
res.writeHead(200, { 'Content-Type': contentType })
res.end(content)
```

## 核心函数说明

### `path.resolve(...paths)`
将路径解析为绝对路径。

**示例：**
```javascript
path.resolve(__dirname, 'public', 'index.html')
// 返回：/项目路径/public/index.html
```

### `path.extname(filename)`
获取文件路径的扩展名（包括点号）。

**示例：**
```javascript
path.extname('index.html')  // 返回: '.html'
path.extname('js/index.js') // 返回: '.js'
```

### `fs.promises.stat(filename)`
异步函数，需要 `await`，获取文件状态信息。

- 文件不存在时会报错（抛出异常）
- 返回一个状态信息对象 `stats`
- `stats.isDirectory()` - 是否是一个目录
- `stats.isFile()` - 是否是一个文件

**示例：**
```javascript
const stats = await fs.promises.stat('index.html')
console.log(stats.isFile())      // true
console.log(stats.isDirectory()) // false
```

### `fs.promises.readFile(filename)`
异步函数，需要 `await`，获取文件的内容。

**示例：**
```javascript
const content = await fs.promises.readFile('index.html', 'utf-8')
// content 是文件的内容（字符串）
```

## 完整流程

```
请求 → 路径处理 → 构建文件路径 → 检查文件是否存在 → 读取文件内容 → 响应客户端
  ↓        ↓            ↓              ↓                ↓              ↓
 /     /index.html  public/...    fs.stat()      fs.readFile()    res.end()
```

## 错误处理

1. **文件不存在**
   - `fs.promises.stat()` 会抛出错误（错误码 `ENOENT`）
   - 使用 `try...catch` 捕获，返回 404

2. **路径遍历攻击**
   - 使用 `path.resolve()` 和 `path.relative()` 确保路径在 public 目录内

3. **读取错误**
   - `fs.promises.readFile()` 可能失败
   - 使用 `try...catch` 捕获，返回 500
