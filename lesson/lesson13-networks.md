路由模式（Router Mode / NAT Mode） vs 桥接模式(更快)

"
运营商网络 → 光猫（PPPoE 拨号 + NAT 转换） → 路由器/设备 (路由)
↓
光猫获取公网 IP
进行 NAT 转换
分配内网 IP 给设备

运营商网络 → 光猫（仅光电转换） → 路由器（拨号 + NAT） → 设备 (桥接)
↓
透明传输
不做任何处理
"
桥接模式更快是因为：

1. 光猫只做物理层转换，不参与网络处理
2. 由性能更强的路由器处理所有网络任务
3. 避免双重 NAT，减少处理开销
4. 网络结构更简单，延迟更低
